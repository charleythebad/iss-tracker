Radar noise vs. the filters

A simulated ground radar at the site measures range, azimuth and elevation, with random noise added. Pick a radar to see how its noise scatters the raw readings, and how the Extended (EKF) and Unscented (UKF) Kalman filters recover the true path.

Is each filter honest about its own error?

ANEES compares each filter's actual error with the error it claims. An honest filter averages 3.0 and stays inside the shaded 95% band; above it, the filter is overconfident.

EKF UKF 95% band for an honest filter

All four radars

The radar is simulated. Readings are the real orbit (SGP4, CelesTrak data) plus random noise; no real sensor data is involved.

Regenerate with python export_site_data.py. Built with Python, Skyfield, NumPy and D3.
